# Screenify — Official Downloads

Welcome to the official release repository for **Screenify**.

This repository hosts downloadable installers and update packages for Screenify. To get the latest version, visit the **[Releases page](https://github.com/yup-ma/screenify-releases/releases)**.

## Download Screenify

| File | Platform | What it's for |
| --- | --- | --- |
| **`screenify-<version>-macOS.dmg`** | macOS | **Recommended for installation.** Open the DMG and drag Screenify into your Applications folder. |
| **`screenify-<version>-macOS.zip`** | macOS | The signed app archive used by Screenify's **automatic updater**. Most users should download the DMG instead. |
| **`screenify-<version>-windows.exe`** | Windows | **Coming soon.** This will be the Windows installer when the Windows version is available. |

> **Note:** Replace `<version>` with the release number, such as `1.0.0`. Actual asset names are listed under each release.

## How to install on macOS

1. Open the [latest release](/releases/latest).
2. Under **Assets**, download the `.dmg` file.
3. Open the downloaded DMG and drag **Screenify** into **Applications**.
4. Launch Screenify from your Applications folder.

If Screenify is already installed, its built-in update checker uses the signed `.zip` package when a new version is available. You normally don't need to download that ZIP manually.

## Windows support

A Windows version of Screenify is **coming soon**. When available, its `.exe` installer will appear alongside the macOS files on the relevant release page.

## Release versions

Each version has its own GitHub Release, tagged with a version such as `v1.0.0` or `v1.0.1`. The files attached to a release belong to that version.
